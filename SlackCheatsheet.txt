Text-Only Quick Reference (For when you don't have Mermaid)
If you just want a simple text snapshot for your notes:

The Data Path:

Raw EHR → Fixed Leak → Feature Engineering → Stacking Ensemble (86% recall) → .pkl Model.

.pkl Model → FastAPI → Docker → AWS ECR.

ECR → AWS EC2 (sudo docker run) → Live API at http://52.15.208.206.

The User Path (Slack):

User types: @Readmission Predictor predict [Patient Text].

Slack sends event via Socket Mode to your EC2 server.

Bot extracts text, removes the @mention, validates the predict command.

Bot calls AWS API http://52.15.208.206/predict.

AWS API returns JSON (Risk Class, Probabilities, Alert).

Bot formats it with Emojis (🔴🟡🟢) and sends it back to Slack.

The "Magic" (tmux):

tmux keeps the bot running 24/7 on EC2, independent of your laptop.
